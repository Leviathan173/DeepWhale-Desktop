DeepSeek 凭据设置

从 platform.deepseek.com 后台生成的 API Key。
平台会话令牌。点击下方按钮，在打开的独立浏览器里登录 platform.deepseek.com/usage，自动抓取并保存，无需手动复制。
若自动获取失败，可手动 DevTools 查看用量请求的 Authorization 头填此框。
令牌保存在本地 config.json，重启后仍有效；若过期失效需重新获取。
输入框留空点击保存 = 保留原值。留空则使用「小鲸鱼记账（估算）」模式。

用量计价（本地记账）

「本地·opencode+Claude」模式按此表算今日金额。
每个提供商选一种计费：按量计费（计入今日金额）或套餐·订阅制（如百炼 tokenplan，不计入）。
峰谷计价勾选后，高峰时段价格按两档价目或单价的 ×2 计（DeepSeek 官方尤其如此）。
用户显式填价目时按类别填写，各列留空会自动填入内置价目（灰底显示，仅展示不落盘）。
opencode 数据按供应商名匹配，Claude Code 数据固定归到「claude」提供商。全部删空 = 恢复默认。
编辑计价表任意字段后自动保存；也可点「保存计价表」手动保存。
