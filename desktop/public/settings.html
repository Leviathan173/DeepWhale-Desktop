DeepSeek 凭据设置

从 platform.deepseek.com 后台生成的 API Key。
平台会话令牌。点击下方按钮，在打开的独立浏览器里登录 platform.deepseek.com/usage，自动抓取并保存，无需手动复制。
若自动获取失败，可手动 DevTools 查看用量请求的 Authorization 头填此框。
留空则使用「小鲸鱼记账（估算）」模式。

用量计价（本地记账）

「本地·opencode+Claude」模式按此表算今日金额。
供应商勾选 按量计费 才计入金额；套餐/订阅制（如百炼 tokenplan）不勾，不计入。
模型「单价」为 元 / 百万 token（作用含缓存在内的全部 token），留空 = 用内置价目。
opencode 数据按供应商名（providerID）匹配；Claude Code 数据按模型名匹配。全部删空 = 恢复默认。
